# miniguia-estudos-notebooklm
Desafio DIO e NotebookLM

## Própósito do guia de estudo
- Estudar os conceitos de desenvolvimento frontend reativo com Javascript na plataforma React.
- Entender os conhecimentos prévios necessários (tecnologias, ferramentas, ambiente etc)
- Da introdução ao aprofundamento em vite, JS, Typescript, Node, Tailwind, Sass 
- Do básico ao deploy em react para web
- Do básico ao deploy em react para apps móveis
- Do básico ao deploy em react para apps desktop
- Do básico ao deploy em NEXTJS
- Aplicação das tecnologias Expo, Redux, Electron
- Integração REST API com backend e com apis expernas públicas
- Boas práticas
- estruturas de hospedagem: vercel etc

## Forma de ação:
Considerar uma mescla dos conhecimentos, criado miniprojetos para evoluir o conhecimento enquanto monta portfólio, considerando também a atualização do github com cada branch, podendo criar um projeto básico, um projeto intermediário para web, um projeto intermediário para mobile, um projeto intermediário para desktop, um projeto intermediário server side, um projeto básico de backend em node para uso, levantamento das apis disponíveis para outros projetos e listá-los para execução, um projeto pro geral
